# Prose and domains

## Prose

Use concrete words. Name the file, field, or command. Put one fact in one home. Link other mentions to that home. Do not narrate the transcript, the review, or the edit history.

Keep a comment only when the code cannot say the rule. Cut restatement.

## Domains

A domain is one decision with one owner. Add an agent when the job needs that decision and the files in scope match. Do not add an agent because the name sounds related.

Archive a note only when it will not guide future work. Never archive toward a quota. Never edit sealed archive bodies.
